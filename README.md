# IFData Bacen - Tratamento de Dados e Análises em R

Este repositório contém a base de dados tratada, scripts e workspaces referentes aos indicadores e dados contábeis do **IF.data (Banco Central do Brasil)**.

## 📁 Estrutura do Repositório

* [**Base de Dados**](./Base%20de%20Dados): Arquivos e bases brutas do IF.data.
* [**ATIVO R. FILE**](./ATIVO%20R.%20FILE): Scripts e dados referentes ao Ativo Total.
* [**LUCRO LÍQUIDO R.FILE**](./LUCRO%20LÍQUIDO%20R.FILE): Scripts e dados referentes ao Lucro Líquido das instituições.
* [**PROVISIONAMENTO R.File**](./PROVISIONAMENTO%20R.File): Scripts e dados de provisão para créditos de liquidação duvidosa.
* [**RESULT. INTERM FINANCEIRA R.File**](./RESULT.%20INTERM%20FINANCEIRA%20R.File): Scripts referentes ao Resultado de Intermediação Financeira.
* [**ROAE R.File**](./ROAE%20R.File): Scripts e análises de Rentabilidade sobre o Patrimônio Líquido ponderado (ROAE).

---
*Organizado para análise do setor bancário brasileiro (2000 a 2024).*
